**ⓕ 읽기 규칙의 수치 조작화 (dev 제안)**:
- 재표집 단위 = 영상(EgoDex) · 시연(LIBERO) · 세그먼트(CALVIN) · 부트스트랩 2000 회 · 95 % 백분위 · 두 판은 같은 재표집 번호(짝).
- 낙폭 Δ = 조건 값 − 기준(`base`) 값(M 실제 변화 복원) · 기준 값 − 조건 값(도움 몫) → 둘 다 **클수록 나쁨**. EgoDex 조건은 같은 표본의 짝 차, 못 본 장면은 표본이 달라 두 평균의 차.
- 한 칸에서 "A 가 낫다" = (Δ_A − Δ_B) 의 CI 가 전부 0 아래 **∧** |Δ_A − Δ_B| ≥ 두 판 기준 값 평균의 5 %. CI 가 0 을 포함하거나 5 % 미만이면 "같음".
- 구분력 = 어느 한 판이라도 |Δ| ≥ 자기 기준 값의 5 % 인 칸만 판정 칸으로 남김. 남는 칸 < 4 면 멈춤(§8-5 그대로).
- 기준에서 "나쁘지 않다" = 기준 값 차의 CI 가 나쁜 쪽으로 5 % 넘게 벗어나지 않음.
- 5 % 하한은 **Vault 기본값 유지**. 근거로 같이 보고할 것 = 같은 판을 마스크 seed 0 · 1 로 잰 기준 값의 차(마스크 잡음 바닥). 이것이 5 % 를 넘으면 규칙을 적용하지 않고 문제로 보고.
- 도움 몫이 기준에서 예측 오차의 5 % 미만(두 판 모두)이면 도움 몫 칸은 "자 불성립"으로 보고하고 판정에 쓰지 않음(분모가 0 근처인 비율 방지).
- 짝 자(토큰 등변성 M · `rope_position.py` · 시연 단위 CI)가 비중첩으로 반대면 "못 가름"(§8-5 그대로).
