- **CoMP (`action-agnostic-visual-rl`) = α · 상각 지각**. 주장: "비싼 P 는 앵커에서 한 번, 그 사이는 앵커 P + 누적 M 으로 **매 스텝 판단**(성공까지 남은 스텝 = temporal distance · 검증기)을 매 스텝 P 만큼 해낸다 — 더 싸게, 그리고 학습된 M 이 raw ΔL 보다 낫다." 무대 = **실시간 가치·검증기**(매 스텝 · 후보 N 개마다 돌아가므로 비용이 직접 걸림). 오프라인 큐레이션은 무대가 아니다(싸야 할 이유가 없음). BC 성공률 격자·DART 는 폐기 — 파일럿(★ 0.81 · P+M 0.61 · P만 0.93)은 "정적 과제에서는 1 초 묵은 P 로 충분 · concat M 은 copycat"이라는 **경계 결과**로 기록.
- **SC (`source-field-alternation`) = β · 잔차 보정**. 주장: "계획대로면 이렇게 변했어야"(A v4)를 뺀 잔차 r_t 로 계획된 다음 행동을 고치면 날것 변화(D)보다 사건을 더 잘 넘긴다(R − D). β 의 학습에는 **가중이 없다**(10-18 밤): 진행도 헤드·청크 가중·V(x_팔) 전부 β 에서 제거. 표준 청크 BC 그대로.
- **가치 모델은 전부 α 소유**(10-18 밤): V(s)(입력 팔별 판독기)와, 혹시 쓰게 될 가치 가중(표준 GR-BC 계열 인용)의 학습·사용은 CoMP 에서. β 는 라벨·폴드·사건 데이터만 공급하고 자기 학습에는 가치를 쓰지 않는다.
- **공통 0 층** = C1-DN 동결(E1 불통과). α 가 인코더를 바꿔도 β 는 불변. 남은 스텝 라벨의 **정의는 SC 가 소유**하고 바꾸면 CoMP 에 통보.
- **왜 이렇게 갈랐나**: 명목 LIBERO 에서는 앵커 사이에 세계가 변하지 않아 M 도 잔차도 할 일이 없다(E3 · SC 0팔 k20 ≥ ★ · α 파일럿 P만 ≥ ★ — 세 번 독립 확인). 두 트랙 모두 **사건(앵커 뒤 세계가 변한 상태)** 이 있는 데이터에서만 측정 가능하므로, 사건 데이터를 만드는 SC 가 공급자, 그 위에서 입력 형식을 비교하는 CoMP 가 소비자다.

## 이 문서의 용어

- **CoMP** — 이 저장소의 모델 (구 CoMP-MAE, 코드 v16). P(form)·M(dynamics) 두 스트림을 서로 재구성시켜 분리시킴. 코드·ckpt 키는 옛 이름 유지
- **deployed-P / P-only** — 배포 시 쓰는 P 스트림 출력. P+M 이어붙임은 causal confusion으로 유해(LIBERO 68.7 vs 2.0)
- **STEP 0/1/2** — 논문 게이트: 0 = 효율 headline, 1 = factorization 인과, 2 = control-level value (A 효율 / B BC)
- **서랍** — 본문에 넣지 않고 supplement에 두는 결과(attach-only). "서랍 재판정" = 그 결과를 다시 판정할지
- **조기 게이트** — 후속 연구를 하루 안에 싸게 죽일 수 있는 선행 조건 (v17: M_student 릿지 프로브 R² > M_teacher)
- **C1-DN** — 주장 모델(09-28): C1 + 10ep, M 입력에 RGB 센서 노이즈(σ~U[0,0.01]) + 쌍 공유 장면 밝기(±1 stop), M-recon 타깃 = 밝기 보존·노이즈 제거 ΔL(`--bright-target aug`). 평가 팔 이름 `PilotM10`
- **v15 / v16 / v17** — `src/models/two_stream_v15.py`의 config 계보. v16 = comp_mae 플래그, v17 = forecast-sufficient (새 파일 아님)
- **관측기 / Fuse** — 동결 인코더의 P·M 토큰을 32개 잠재 토큰(z)으로 묶는 작은 Perceiver. z_PP = {앵커 P, 현재 P}(비싼 방법) · z_PM = {앵커 P, M 조각들}(싼 방법) · v3 = 5프레임 조각만, v4 = + 부분 조각(매 스텝)
- **위치 너머 몫** — R²(z + 앵커 손 위치) − R²(손 위치만). 손 위치로 공짜로 맞히는 몫을 뺀 순수 움직임 정보
