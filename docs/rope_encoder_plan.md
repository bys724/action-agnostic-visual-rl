# RoPE 인코더 시도 — C1-DN 의 위치 인코딩을 절대(APE) → 2D RoPE 로 (사전 등록 v0 · 2026-11-23 Vault 세션 · 사용자 확정)

> **지위**: 이 문서가 정본. `STATUS.md` "열린 것" 블록과 결정 이력은 포인터.
> **동결 해제 범위**: 10-27 처분("측정 종료 · 집필")은 **이 시도 한 건에만** 풀린다. 집필(`paper_finalization_plan.md` §5) · 논문 주장 모델 C1-DN · α 판정 Round 1~8 전부 **불변**. 이 시도는 논문에 들어가지 않는다(주장 아님 · 부록도 아님).
> **표기**: 【확정】 = 사용자 11-23 결정 · 【기본값】 = Vault 가 정한 값(실행 전 질문 가능) · ⚠ = dev 가 저장소 사실로 채워 결과 전 보고.

## 0. 한 줄

C1-DN 과 같은 가중치·데이터·레시피에서 **위치 인코딩만** 학습된 절대 위치 임베딩(`pos_embed_p/m`) → 블록 안 **2D RoPE**(`build_2d_rope_freqs` · `apply_rope` · 코드에 이미 있음 · `--use-ape` 를 빼면 기본 경로)로 바꿔 이어 학습하고, **표현이 성립하는지(건강 관문)** 와 **위치 정보가 토큰에 어떻게 남는지(보고 행)** 를 잰다. **이득 판정은 두지 않는다.**

## 1. 왜 하는가 · 왜 판정이 없는가

- 출처 = SC 행동 기반 예측 모델 시험(SC `docs/action_predictor_prereg.md` · 11-23 논의). 사용자 동기【확정】: 움직임 예측은 국소 · 평행이동 불변 규칙이라 **상대 위치**가 맞는 귀납 편향일 수 있다. 반대편도 적어 둔다 [추정]: 고정 카메라에선 절대 위치가 장면 배치 정보이기도 해 득실 미정. 참고 = RoPE-ViT(Heo et al., ECCV 2024) 해상도 외삽 · 영상 월드모델 계열 3D RoPE(V-JEPA 2 [미확인]).
- **분담【확정】**: SC 는 지금 C1-DN(절대 위치) **고정**으로 흐름 판 · 일반화 시험까지 간다(인코더 변경은 버전 경계에서만). CoMP 는 RoPE 판을 **만들어 두고 성립 여부만** 본다. RoPE 가 움직임 예측에 실제로 득인지는 **SC 가 자기 자로**(예측기 안 2D RoPE 팔 · 또는 다음 버전 경계에서 이 인코더로 재측정) 판단한다 — 계약 v2: 두 저장소는 서로의 수치를 자기 판정에 쓰지 않는다. 그래서 여기엔 **"RoPE 가 낫다/못하다" 판정이 없다.**
- CoMP 자체 질문은 하나【기본값】: "위치 인코딩을 바꿔도 CoMP 의 두 성질(M 접지 · P 가독성)이 유지되는가." 유지되면 SC 다음 버전 경계의 **인코더 후보**가 된다. 유지되지 않으면 그대로 기록하고 닫는다.

## 2. 학습 — 두 판 (단일 변수)

| 판 | 위치 인코딩 | 그 밖 |
|---|---|---|
| **R (RoPE)** | `--use-ape` 제거 → `freqs_cis` 버퍼 · `pos_embed_p/m` 없음 | C1-DN 가중치로 초기화(`--init-from` · pos_embed 키는 버림 ⚠) · 데이터 · 증강 · 손실 · 에폭 · LR = 대조 판과 동일 |
| **A (APE 대조)** | C1-DN 그대로(`--use-ape`) | 같은 초기화 · 같은 이어 학습 → "에폭을 더 돌린 효과"를 R 에서 분리 |

- **레시피【기본값】** = C1 → C1-DN 이어 학습 단계(`two_stream_v15b_refine_comp_s_denoise_augtgt` · 10 ep · 센서 노이즈 제거 · 밝기 보존 타깃 · 로그 "Model args")를 그대로 · 데이터 = 그 단계의 EgoDex 분할 그대로. **LIBERO 데이터는 안 쓴다**(§4-h 와 다름 · 도메인 질문 아님). LR ⚠ = 그 단계의 값을 쓰되, R 판은 위치 기전이 바뀌어 손실이 처음 크게 뛰는 것이 정상 — 1 ep 안에 A 판 손실의 1.5 배 안으로 못 들어오면 멈추고 보고(결과 전 고정 · dev 가 수치 확인 뒤 조정 제안 가능).
- **비용 참고** [추정 · §4-h 와 같은 방식이면]: 판당 10 ep ≈ 2.8 h × H100 3 → 두 판 ≈ 17 GPU·h. 1-GPU sanity(손실 감소 · NaN 0 · `pos_embed` 키 없음 확인 · 처리량) → **R 판 최소 잡 먼저** → A 판 → 관문 → 보고. "최소 잡 보고 전 전체 제출 금지" 관행 유지.
- ⚠ dev 확인(결과 전 · 코드 안 고치고 보고): ① `--init-from` 이 `pos_embed_*` 키 불일치를 어떻게 다루나(strict 여부 · 버리는 경로 있나) ② 디코더 `decoder_pos_embed` 는 학습 절대 위치 그대로다 — 이번 판은 **인코더만** 바꾼다(디코더까지 RoPE 는 범위 밖) ③ `two_stream.py` 로더의 `use_ape` 자동 감지(`encoder.pos_embed_m` 키 유무)가 R 판 ckpt 를 RoPE 로 올리는지 ④ RoPE 경로가 마지막으로 학습에 쓰인 시점(어느 run · 깨진 적 없나).

## 3. 건강 관문 (결과 전 고정 · 판정 = "성립/불성립" 둘뿐)

STEP 1 same-probe(LIBERO-object · attentive · gap 20 · C1-DN `fdn_*` 설정 그대로 · probe seed 3) 를 **R · A 두 판**에 돌린다. 기준 = E1 때 쓴 셋 그대로:

| 항목 | 성립 기준 |
|---|---|
| P identity | ≥ 0.9 (C1-DN 1.000) |
| M motion 위치 너머 몫 Δ | ≥ C1-DN(+0.320) 의 절반 |
| M identity 잔여 | ≤ 0.291 (E1 문턱 · C1-DN 0.241) |

- **R 판 셋 다 성립 = "RoPE 인코더 성립 · SC 다음 버전 경계 후보"**. 하나라도 불성립 = "성립 안 함" 기록 · 재시도 없음(LR · 에폭 늘려 맞추지 않는다).
- A 판은 **기준점**이다. A 판이 C1-DN 에서 멀어지면(어느 항목이든 문턱 밖) "이어 학습 자체가 표현을 움직였다"고 적고 R 판 읽기에 그 사실을 병기한다. A 를 R 의 기준으로 바꿔 쓰지 않는다(문턱은 위 표 고정).

## 4. 보고 행 (판정 아님 · 전부 학습 0 · R · A · C1-DN 세 모델)

1. **위치 선형 판독**: P 패치 토큰 하나 → 패치 번호(196 클래스) 선형 판독 · 격리 에피소드 · top-1 과 이웃 1 칸 안. SC 0 단 정의와 같게(SC 측정 C1-DN 0.977). **RoPE 판에서 이 값이 떨어지면 SC 예측기는 위치 임베딩을 자기 쪽에서 더해야 한다**(SC 사전 등록 §5 0 단 ③ 규칙 · 문턱 0.90) — 그 사실이 이 행의 쓸모다.
2. **쉬프트 등변성**: 같은 프레임을 16 px(한 패치) 이동한 입력에서 P · M 패치 토큰이 함께 한 칸 이동하는 비율(이동 전 토큰과 이동 후 이웃 토큰의 코사인 · 경계 패치 제외). RoPE 가 APE 보다 높을 것이 **기대** [추정]이지만 판정 아님.
3. **α 4-a 선행 판독**(앵커 P + 누적 M 이 앵커 뒤 움직임을 담는 몫 · libero_object · 나이 1..20 평균 · seed 3) — 기존 파이프라인 그대로 세 모델 비교 · 서술은 "위치 인코딩이 바꾼 양"까지.
4. 학습 곡선(두 판 · P-recon · M-recon 각각) · EgoDex eval 손실.

## 5. 하지 않는 것 (이유 한 줄씩)

1. **"RoPE 가 낫다" 판정** — SC 의 자로 재는 질문이고 CoMP 수치로 SC 결정을 대신하지 않는다(계약 v2).
2. **SC 에 자동 전달** — 성립해도 SC 는 지금 판을 C1-DN 으로 끝낸다. 통보만(`STATUS.md` 한 줄 · SC `VAULT_SYNC_TODO.md` 는 Vault 가 쓴다).
3. **디코더 RoPE · 해상도 외삽 · 데이터 변경 · 에폭 연장 · LR 탐색** — 단일 변수(위치 인코딩)가 흐려진다.
4. **집필 중단 · 논문 수치 변경** — 이 시도는 논문 밖.
5. **관문 미달 뒤 재시도** — 한 번 보고 닫는다. 필요하면 Vault 에 새로 등록.

## 6. 순서

1-GPU sanity(⚠ ①~④ 보고 포함) → R 최소 잡 → 손실 규칙 확인 → R 본학습 → A 본학습 → §3 관문(두 판) → §4 보고 행 → `STATUS.md` 갱신 줄 + 열린 것 블록에 결과 → **멈춤**(SC 통보는 Vault).
