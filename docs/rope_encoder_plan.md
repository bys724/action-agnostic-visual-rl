# RoPE 인코더 — 위치 의존성을 낮춘 범용 인코더가 되는가 (사전 등록 v1 · 2026-11-23 Vault 세션 · 사용자 확정)

> **지위**: 이 문서가 정본. `STATUS.md` "열린 것" 블록과 결정 이력은 포인터. v0(같은 날 · "판정 없음 · 건강 관문만")는 사용자 지시로 **같은 날 v1 로 대체** — 결정 이력 참조.
> **동결 해제 범위**: 10-27 처분("측정 종료 · 집필")은 **이 실험 한 건에만** 풀린다. 집필 · 논문 주장 모델 C1-DN · α 판정 Round 1~8 은 불변. 결과가 논문에 들어갈지는 **결과 뒤 사용자 결정**(미리 정하지 않음).
> **표기**: 【확정】 = 사용자 11-23 결정 · 【기본값】 = Vault 가 정한 값(실행 전 질문 가능) · ⚠ = dev 가 저장소 사실로 채워 결과 전 보고.

## 0. 한 줄

C1-DN 의 위치 인코딩을 학습된 절대 위치(APE · `pos_embed_p/m`)에서 블록 안 **2D RoPE** 로 바꾸고, **바꾸는 과정에서 생기는 문제를 분석·해결한 뒤**, 그 인코더가 **① 위치에 덜 의존하고 ② 범용 기능(분포 밖 판독 · 해상도 외삽 · CoMP 두 성질)이 좋아졌는지**를 CoMP 의 자로 판정한다. 두 단계로 간다 — **공학 단계**(고치며 성립시키기 · 자유)와 **판정 단계**(규칙 고정 · 한 번).

## 1. 왜 하는가

- 출처 = SC 행동 기반 예측 모델 시험(SC `docs/action_predictor_prereg.md` · 11-23 논의). 사용자 동기【확정】: 움직임 예측은 국소 · 평행이동 불변 규칙이라 **상대 위치**가 맞는 귀납 편향이고, 절대 위치에 묶인 표현은 "어디에 있는가"를 "무엇이 일어났는가"에 섞는다. 사용자 요구【확정 · v1】: 단순 교체가 아니라 **문제를 풀면서 끝까지 가서 범용성이 실제로 좋아지는지 확인**할 것. 그 확인은 CoMP 저장소에서.
- 반대편 [추정 · 결과 전 기록]: 고정 카메라 데이터(LIBERO)에선 절대 위치가 장면 배치 정보이기도 하다. 위치 의존성을 낮추면 **그 정보에 기대던 판독은 내려갈 수 있다** — 그래서 판정 ②에 "같은 분포 성질 유지"를 넣는다. 참고 = RoPE-ViT(Heo et al., ECCV 2024 · 해상도 외삽 · 위치 일반화) · 영상 월드모델 3D RoPE(V-JEPA 2 [미확인]).
- **분담【확정】**: SC 는 지금 C1-DN(절대 위치) **고정**으로 흐름 판 · 일반화 시험까지 간다. CoMP 가 성공한 인코더는 **다음 버전 경계**에서 SC 에 후보로 통보한다. 두 저장소는 서로의 수치를 자기 판정에 쓰지 않는다(계약 v2) — 이 문서의 판정은 **CoMP 자**(판독 · 등변성 · 분포 밖 벤치)로만.

## 2. 공학 단계 — 성립시키기 (고쳐도 됨 · 전부 기록)

**목표**: RoPE 판 R 이 **건강 관문(§4-1) 셋을 통과**하는 상태로 만든다. 여기서는 문제를 **분석하고 고치는 것이 일**이다. 단, 무엇을 고쳤는지와 왜인지를 아래 로그 표에 전부 남긴다.

| 항목 | 내용 |
|---|---|
| 출발점【기본값】 | C1-DN(`two_stream_v15b_refine_comp_s_denoise_augtgt/…/checkpoint_epoch0010.pt`) 가중치로 초기화(`pos_embed_*` 키 버림 ⚠) · `--use-ape` 제거 → `freqs_cis` 경로 · 데이터 · 증강 · 손실 · 에폭(10) = C1 → C1-DN 이어 학습 단계 그대로 · EgoDex(LIBERO 안 씀 · 도메인 질문 아님) |

| 예상 이슈(dev 가 먼저 점검 ⚠) | ① `--init-from` 의 `pos_embed_*` 키 불일치 처리(strict 여부) ② APE 가중치로 학습된 어텐션에 RoPE 를 얹으면 초기 손실 급등 — 워밍업 · 낮은 LR · 또는 처음 N 스텝 어텐션만 학습 같은 안정화가 필요할 수 있음 ③ CLS 토큰(RoPE 미적용 `has_cls=True`)과 패치 사이 상호작용 변화 · P 스트림 `num_p_cls` 처리 ④ **디코더 `decoder_pos_embed` 는 절대 위치** — 인코더만 RoPE 면 복원 손실이 디코더 APE 로 위치를 다시 끌어들일 수 있음 → 디코더 RoPE 는 **공학 단계의 선택지**(dev 가 근거를 들어 제안 · 사용자 확인 뒤) ⑤ RoPE 경로가 마지막으로 학습에 쓰인 시점과 그때 결과(깨진 적 없나) ⑥ 2D 주파수 θ · 해상도 14×14 에서의 주파수 분포 |

## 3. 판정 단계 — 규칙 (결과 전 고정 · 공학 단계 끝난 뒤 **한 번**)

판정 대상 = 공학 단계가 낸 **최종 R** · 같은 수정이 들어간 **최종 A** · **C1-DN**(변경 없음). 전부 동결 인코더 · 판독기만 학습 · probe seed 3 · CI 병기 · 같은 split.

### 3-1. 건강 관문 (성립 조건 · 공학 단계 출구와 같은 문턱)

STEP 1 same-probe(LIBERO-object · attentive · gap 20 · C1-DN `fdn_*` 설정) · 기준 = E1 셋: **P identity ≥ 0.9 · M motion 위치 너머 몫 Δ ≥ C1-DN(+0.320) 의 절반 · M identity 잔여 ≤ 0.291.** 셋 다 통과한 R 만 아래로.

### 3-2. 판정 ① 위치 의존성이 낮아졌는가

| 자 | 재는 법 | 판정 |
|---|---|---|
| **평행이동 교란 낙폭(주)** | 평가 입력만 k px 평행이동(패딩 = 반사 · k ∈ {8, 16, 32} · 학습 0) 뒤 3-1 의 M motion 위치 너머 몫을 다시 잼. 낙폭 = 원본 − 이동 | **R 의 낙폭 < A 의 낙폭**, k 셋 중 ≥ 2 에서 seed 3 CI 비중첩 |
| 쉬프트 등변성(보조) | 16 px(한 패치) 이동 전후 P · M 패치 토큰의 "이웃 칸으로 옮겨 갔는가" 코사인 비율(경계 패치 제외) | R > A (CI 비중첩) — 보조 · 주 판정 못 대신함 |
| 위치 선형 판독(보고) | P 패치 토큰 → 패치 번호 196 클래스 선형 판독 · top-1(SC 0 단 정의 · C1-DN 0.977) | 판정 아님. 낮아지면 "토큰이 절대 위치를 덜 품는다"로 적고 **SC 통보 사항**(SC 예측기가 위치 임베딩을 자기 쪽에서 더해야 함 · SC 규칙 0.90) |

### 3-3. 판정 ② 범용 기능이 좋아졌는가

| 자 | 재는 법 | 판정 |
|---|---|---|
| **분포 밖 판독(주)** | STEP 2-A 의 OOD 프로빙 격자(4 벤치 · `probe_action_*.sbatch` · 동결 인코더 · 선형 판독 · 벤치 이름 ⚠ dev 확정) | **R ≥ A 전 벤치**(어느 벤치에서도 CI 비중첩 하락 없음) **∧ ≥ 2 벤치에서 CI 비중첩 상승** |
| **해상도 외삽(주)** | 224 학습 그대로 288 · 320 입력(패치 수 증가 · RoPE 는 주파수 외삽 · APE 는 보간 ⚠ 보간 방식 고정)으로 3-1 same-probe 재측정 · 낙폭 = 224 − 외삽 | **R 의 낙폭 < A 의 낙폭** 두 해상도 모두 CI 비중첩 |
| 같은 분포 유지(가드) | 3-1 세 값이 C1-DN 대비 **−0.05 안**(P identity 는 ≥ 0.95) | 위반 시 ② 성립 선언 못 함 — "위치 정보에 기대던 몫을 잃음"으로 기록 |
| α 4-a 선행 판독(보고) | 앵커 P + 누적 M 의 앵커 뒤 움직임 몫 · libero_object · 나이 1..20 · seed 3 | 판정 아님 · 세 모델 비교 |

### 3-4. 결론 문장 (미리 적어 둔 네 칸)

- ① ∧ ② 성립 → **"위치 의존성을 낮춘 RoPE 인코더가 범용 판독 · 해상도 외삽에서 C1-DN 을 넘는다"** → SC 다음 버전 경계 후보 · 논문 반영 여부 = 사용자.
- ① 성립 · ② 불성립 → "위치 의존성은 낮아졌으나 범용 기능 이득은 없다"(가드 위반이면 "위치 정보를 잃은 비용") → 후보 아님 · 기록.
- ① 불성립 · ② 성립 → "이득은 있으나 위치 의존성 기전으로 설명되지 않는다"(이어 학습 · 다른 요인) → A 와의 차이로 서술 · 후보 여부 Vault.
- 둘 다 불성립 → 닫음.
- 공학 단계에서 성립 못 함 → "RoPE 전환 불성립(이유)" · 판정 열지 않음.

## 4. 하지 않는 것

1. **판정 단계에서 고치기.** 판정 뒤 수정은 전부 "사후 변경"으로 적고 재판정은 Vault 등록 뒤.
2. **SC 코드 · SC 자 사용.** 통보만.
3. **데이터 · 에폭을 R 에만 늘리기.** 늘리면 A 도.
4. **집필 중단 · 논문 수치 변경.** 결과 뒤 사용자 결정 전까지 논문 밖.
5. **문턱 사후 변경.** 공학 단계에서 알게 된 것으로 §3 문턱을 바꾸지 않는다(바꿔야 하면 Vault 에 묻고 판정 전에).

## 5. 순서

⚠ ①~⑥ 점검 보고(코드 안 고치고) → 1-GPU sanity → **R 최소 잡** → 공학 단계 반복(로그 표) → R 관문 통과 → A 본학습(같은 수정) → 판정 단계 3-1 → 3-2 · 3-3 · 보고 행 → 결론 문장 네 칸 중 하나 → `STATUS.md` 갱신 줄 + 열린 것 블록 → **멈춤**(SC 통보는 Vault).
